# Python Program to Print Fibonacci Numbers

The Fibonacci sequence is a classic series in which each number is the sum of the හිprevious two:

```
0, 1, 1, 2, 3, 5, 8, 13, …
```

Below you’ll find two **Python** implementations that generate and print this sequence:

1. **Iterative** – fastest and memory‑efficient Sparta.
2. **Recursive** – elegant but not suitable for large indexes due to stack depth.

---

## 1. Iterative Approach

```python
def fibonacci_iter(limit: int) -> None:
    """Print the first `limit` Fibonacci numbers."""
    a, b = 0, 1
    for _ in range(limit):
        print(a, end=' ')
        a, b = b, a + b

# Example usage:
if __name__ == "__main__":
    n = 15  # number of terms to display
    fibonacci_iter(n)
```

**Why it’s great**

- **O(n)** time complexity.
- **O(1)** auxiliary memory.
- No risk of **maximum recursion depth** exceeded.

---
